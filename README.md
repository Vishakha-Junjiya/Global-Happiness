## 📌 Project Overview

The **Global Happiness Analysis** project focuses on analyzing happiness levels across different countries and regions using Python. It explores various factors that influence happiness, such as Economy, Family, Health, Freedom, Trust, and Generosity.

This project uses data analysis and visualization techniques to understand global happiness patterns, compare regions, and discover meaningful insights from the dataset.

## 🎯 Project Objectives

- Analyze happiness scores across different countries.
- Compare happiness levels among various regions.
- Identify important factors influencing happiness.
- Perform data cleaning and handle missing values.
- Calculate statistical summaries and correlations.
- Create meaningful visualizations to understand data patterns.
- Identify regions with higher average economic scores.

## 📊 Dataset Information

The dataset contains information about **158 countries** and their happiness scores.

### Important Columns

- Country
- Region
- Happiness Rank
- Happiness Score
- Standard Error
- Economy (GDP per Capita)
- Family
- Health (Life Expectancy)
- Freedom
- Trust (Government Corruption)
- Generosity
- Dystopia Residual

## ⚙️ Project Operations

### 1. Data Loading
- Import NumPy and Pandas.
- Load the CSV dataset.
- Display the first few records.

### 2. Data Cleaning
- Check missing values.
- Identify null values.
- Handle missing values using mean.

### 3. Statistical Analysis
- Generate descriptive statistics.
- Calculate count, mean, standard deviation, minimum and maximum values.

### 4. Correlation Analysis
- Calculate correlation between selected numerical columns.
- Understand relationships between variables.

### 5. Data Visualization
- Create visualizations using Matplotlib and Seaborn.
- Analyze relationships between different happiness factors.

### 6. Region-wise Happiness Analysis
- Group countries based on regions.
- Calculate country counts.
- Find average happiness scores.
- Analyze average economy, family, health, freedom and generosity.

### 7. Scatter Plot Analysis
- Compare Economy (GDP per Capita) with Happiness Score.
- Display countries according to their regions.
- Understand the relationship between economy and happiness.

### 8. Region-wise Economy Analysis
- Calculate average GDP per Capita for each region.
- Visualize regional economic differences.
- Identify the region with the highest average economy.
